# سامانه پیشنهاد خودرو برای لیزینگ

اپلیکیشن فارسی که سقف قسط قابل قبول را از روی حقوق خالص، نسبت قسط به حقوق، و توان پرداختی اعلام‌شده حساب می‌کند؛ سپس قیمت خودروها را با پیش‌پرداخت، نرخ سالانه و مدت قرارداد به قسط ماهانه تبدیل می‌کند و گزینه‌های قابل پرداخت را مرتب نشان می‌دهد.

## اجرا در Windows CMD

اگر محیط مجازی را هنوز نساخته‌اید:

```bat
python -m venv .venv
```

سپس در پوشهٔ پروژه این دستورها را اجرا کنید:

```bat
call .venv\Scripts\activate.bat
python -m pip install -r requirements.txt
python -m streamlit run app.py
```

استفاده از `python -m streamlit` باعث می‌شود برنامه از همان پایتون فعال‌شدهٔ محیط مجازی اجرا شود، حتی اگر دستور `streamlit` در PATH ویندوز نباشد.

## منبع قیمت و فرض‌های مالی

برنامه تلاش می‌کند فهرست قیمت بازار را از API عمومی نمودا دریافت کند. طبق مستندات این منبع، داده‌های قیمت به‌صورت میانه و هر شش ساعت تازه می‌شوند. اگر API در دسترس نباشد یا قالب پاسخ تغییر کرده باشد، فهرست قیمت را با CSV بارگذاری کنید. CSV باید ستون نام خودرو و قیمت روز برحسب تومان داشته باشد.

فرمول قسط از نوع اقساط مساوی است. نرخ، پیش‌پرداخت، مدت و نسبت حقوق قابل تنظیم‌اند و باید مطابق محصول واقعی شرکت لیزینگ تنظیم شوند. مبلغ نهایی قرارداد ممکن است هزینه‌ها و شرایط دیگری هم داشته باشد.
